## Sobre o App
Aplicativo mobile desenvolvido em React Native com Expo para gerenciar listas de compras de produtos em comércios locais do bairro.

### Funcionalidades
- Cadastro de produtos com nome, preço, categoria e descrição
- Marcar produtos como comprados
- Persistência local dos dados (AsyncStorage)
- Interface simples e intuitiva
- Navegação entre telas

## Como Rodar

### Pré-requisitos
- Node.js 22.13 ou superior na linha 22 (ou 24.3+ na linha 24)
- npm ou yarn
- Expo CLI
- Expo Go no celular (para testes)

### Instalação

1. Clone o repositório:
   git clone [URL_DO_REPOSITORIO]
   cd vitrine-do-bairro-av2

2. Instale as dependências:
   npm install

3. Inicie o projeto:
   npx expo start

4. Escaneie o QR Code com o Expo Go (Android/iOS) ou pressione:
   - "a" para abrir no Android
   - "i" para abrir no iOS (simulador)
